# Round T (T1) — button builder falsification record

Each rule below was reverted alone in the T1 worktree, against its own database
(`nexa_test_t1`), with no other suite running against it. Only the named tests were run
(`vitest -t`), and the file was restored byte for byte (checked by SHA-256) before the next
mutation; rows that mutate `packages/contracts` rebuilt the contracts `dist` after the
mutation and again after the restore. Every row was run against the tree that carries the
tests below; each cited test passes on the unmutated tree. `docs/round-t-button-builder-audit.md`
§13 names the targets.
