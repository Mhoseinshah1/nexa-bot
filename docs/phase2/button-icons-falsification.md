# Phase 2 UX wave, Items 1 and 3: falsification

Branch `phase2/a-button-icons`. Each row reverts ONE rule that the branch adds or restores,
runs only the named test file, and restores the source. The driver is
`scripts/mutate-p2-button-icons.py`, modelled on `scripts/mutate-a2.py`:

- a `packages/contracts` mutant rebuilds the package before the run and again after the
  restore, because the tests import its `dist`;
- a mutant counts as KILLED only when tests ran and at least one FAILED;
- integration mutants ran on a database of their own (`nexa_test_p2a`).

Design and evidence: `docs/phase2/button-icons.md`. The superseded round-T row R-01
(`docs/round-t-t3-falsification.md`) is replaced by P2I-01. P2I-32..39 were added by the review
of PR #215 (B1: an operator-typed inline icon never switches a bot off; N1, N2, N6).
