# Phase 2 UX wave, Item 2: falsification

Branch `phase2/b-category-icons`. Each row reverts ONE rule that the branch adds, runs only the
named test file, and restores the source. The driver is `scripts/mutate-p2-category-icons.py`,
modelled on `scripts/mutate-a2.py` and `scripts/mutate-p2-button-icons.py`:

- a `packages/contracts` mutant rebuilds the package before the run and again after the
  restore, because the tests import its `dist`;
- a mutant counts as KILLED only when tests ran and at least one FAILED;
- integration mutants ran on a database of their own (`nexa_test_p2b`).

Design and evidence: `docs/phase2/category-icons.md`. The shared icon transport and its one
icon-less retry are Item 3's and are falsified in `docs/phase2/button-icons-falsification.md`.

**Result: 40 of 40 mutants killed (52 failing tests in all). No survivor.** P2C-31..40 and the
new P2C-03/04/06 come from the review of PR #217 (the after-emoji grammar, the value's bound and
key, and the refusal naming its categories); the whole driver was re-run after them.
