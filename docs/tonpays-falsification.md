# WP11A TonPays — falsification record

Each rule reverted ALONE against the rebased branch, the named test file run against a
freshly created test database, and the file restored byte-for-byte (the driver refuses to
continue if `git diff` of the mutated file is not empty). TP-05 and TP-06 had no test
before this record; the two tests they cite were added with it, and each mutation re-run.

TP-13..TP-20 are the six findings of the one Codex review of this PR, each fixed with the
test it cites. TP-18 survived its first run — no test held a lease another worker had
taken — until the repository-level test it cites was added.
