# PR-1 inventory (services and orders): before -> after

Nothing is removed. Hooks, queries, query keys, permissions, mutations, confirm dialogs, reason fields and validation are unchanged;
only the layout around them moved. «No count» = the API sends a keyset page and no total, so no count chip or chip count is drawn.
