# PR-6 (part B): before/after inventory — bots, bot buttons, appearance, content, terms, client apps

Presentation only: every query, mutation, permission prop, confirm dialog, validation and idempotency key is the page's own,
unchanged. No endpoint was added and no contract changed (the QR page sends the existing `qrTemplateSchema` fields only,
`quietZoneModules` among them). No time input exists on these pages, so `TimeField24` is not needed. Kit pieces used: `LayoutDnd`
(extended with `onSelect` and `className`, a per-instance hint id), `Disclosure`, `ListFreshness`, `PageHead` (`count`).

## Decisions

- The inspector's placement controls and the «حذف از منو» button are removed (owner: reorder only by drag and keyboard; the free box removes).
- The service layout's show/hide switch became the free box; a hidden button keeps no position (stored in trailing rows).
- Count chips: only `/bots` (the list is complete). Content / client apps / terms have no server total chip.
