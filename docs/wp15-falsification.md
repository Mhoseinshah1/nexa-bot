# WP15 G1–G7 — falsification record

The owner's decisions on the seven WP15 findings (`docs/wp15-provider-hardening-audit.md`
§3), each rule reverted ALONE against the working tree of commit `7740470`, the named
test file run, and the tree restored byte-for-byte before the next mutation (a driver
that rewrote the file from its saved content and checked `git diff` was empty after the
pass). Integration rows ran against a real PostgreSQL and the real-socket RickPanel,
Marzban and 3X-UI fakes; nothing here touched `packages/contracts`.

What these rows prove is that the tests can tell each rule from its absence. They do not
prove a real panel behaves like its fake; that is §3's "live-provider evidence" column.
