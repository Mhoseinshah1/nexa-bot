# F5 — trial and referral cleanup falsification record

F5 makes each panel's own trial the one switch in front of a free trial (the `trials`
feature flag is retired), takes the trial out of the catalogue — it is a main-menu action
only, drawn while a panel offers one — and takes the referral button off the wallet.
Migration `0144_f5_trial_flag_retired` carries each tenant's effective switch across.

Each rule below was reverted alone, the named test was run, and the file was restored from
a copy taken before the edit, its SHA-256 compared with the original before the next
mutation. A mutation of `packages/contracts` was run against a rebuilt package, which the
tests import, and the package was rebuilt again after the restore.
