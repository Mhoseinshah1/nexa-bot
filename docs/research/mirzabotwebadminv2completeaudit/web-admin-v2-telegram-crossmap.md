# Web ↔ Telegram Crossmap — 13 domains

| Domain | Web feature | Telegram equivalent | Same? | Notes | Confidence |
|---|---|---|---|---|---|
| **Users** | browsable, sortable, paginated list with 6 sort orders + tier URLs; consolidated 4-tab detail record | search-by-identifier → 35-button action keyboard | **DIFFERENT** | Web = record view; Telegram = action surface. Web-only fields: `امتیازات کاربر`, `ارسال اطلاع رسانی`, `محدودیت تغییر لوکیشن`, `سقف منفی شدن موجودی`. No Add User in either. | VERIFIED |
| **Admins / RBAC** | `Admin(bot, username, permission)` with a **7-value** role enum; create + delete only | a **4-role** model | **CONTRADICTION** | CON-WEB-001. No Role/Permission entity in either. | VERIFIED |
| **Orders** | 7-status × 3-type filter, date range, price range, per-panel and per-product multi-select | none — statistics only | **WEB_ONLY** | The single biggest web-only capability. | VERIFIED |
| **Services** | `/invoice/service` append-only ancillary ledger with 7 operation types | aggregate counters only | **WEB_ONLY** | Includes 3 Mini-App types Telegram never reports. | VERIFIED |
| **Panels** | list + 6-tab detail, 13 `status_*` capability booleans, provider-specific tabs; **no create**; delete per row | full create wizard (17 provider types) + 24-button per-panel menu incl. connection editing | **COMPLEMENTARY** | Web can't create or edit connections; Telegram can't filter, sort or see provider-specific tabs cleanly. `پنل پاسارگارد` only visible in web. | VERIFIED |
| **Store / catalog** | product list + 4-form detail (`limit_user`, hide-per-panel, per-product inbound, display order); 7 categories with inline edit | store menu with product/category management | **DIFFERENT** | Web edit exposes 3 things web *create* and Telegram don't. `data_limit_reset` (بدون ریست/روزانه/هفتگی/ماهانه) is web-only. | VERIFIED |
| **Pricing** | 4-dimensional custom-service price bands with an optional per-user override | `قیمت سرویس دلخواه` prompt only | **WEB_ONLY (schema)** | Resolves the phase's designated high-priority unknown. | VERIFIED |
| **Discounts** | 10-field create form (percentage-only, `همه/خرید/تمدید`, product + panel scope, per-user cap, expiry, first-purchase) | 10-step conversational creation | **SAME shape** | The list page redirects (SOURCE_BUG-WEB-003) so redemptions could not be compared. | VERIFIED (form) |
| **Finance / gateways** | 11 fixed gateways × (enable, 3 eligibility numbers, min/max, cashback %) | 11 gateways × 16 settings incl. credentials, colour, order, auto-approval | **COMPLEMENTARY** | Web tunes; Telegram configures. Web has no credentials at all. | VERIFIED |
| **Payments** | list + detail by 10-hex code, status and method columns | gateway totals in statistics only | **WEB_ONLY (detail)** | Status vocabulary differs between web pages — UNK-WEB-005. | VERIFIED |
| **Receipts** | — | `💵 رسید های تایید نشده` full approve/reject flow | **TELEGRAM_ONLY** | | VERIFIED |
| **Resellers** | tier fields on the user record + reseller-bot token forms; both reseller list pages empty or redirecting | reseller membership fee, monthly floor, expiry, 2 bulk bot operations, reseller statistics | **TELEGRAM_ONLY (policy)** | Web holds per-user reseller fields; policy lives in Telegram. | PARTIAL |
| **Settings** | shop settings (17 flags incl. per-tier cashback), gateway tuning, notification id, keyboard builder, theme | 15 General Settings sections, 31 bot capabilities, bot texts, commands, QR background, optimisation | **COMPLEMENTARY** | Per-tier cashback is web-only; optimisation/cleanup, QR background, bot commands and start gift are Telegram-only. | VERIFIED |
| **Texts** | **608** `users.*` keys with stored defaults and per-key revert | **36** editable items | **CONTRADICTION → web authoritative** | CON-WEB-002. | VERIFIED |
| **Reports** | 7 KPIs + 10 charts (composition, payment method/status, invoice conversion, per-panel sales, ancillary types, weekday, peak hours, user growth, 7-day moving average) + share-of-revenue table; 7/30/90 presets | 11 report types, all-time card, custom range with a financial block, product A/B comparison, leaderboards, per-user report | **COMPLEMENTARY** | Web has charts and total revenue; Telegram has custom ranges, leaderboards, per-user reports and reseller reporting. Neither is a superset. | VERIFIED |
| **Automation** | none | `⛏️تنظیم کامند ربات`, reseller bulk update/webhook, 3-minute panel ping (code-only) | **TELEGRAM_ONLY** | No cron/scheduler page exists in the web at all. | VERIFIED |
| **Audit** | `/admin/logs` — actor, action sentence, customer id, time, IP; 1700 rows, no filter/export | no equivalent | **WEB_ONLY** | No before/after values → activity feed, not an audit trail. | VERIFIED |
