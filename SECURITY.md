# Security policy

## Reporting a vulnerability

Please report security problems privately, through GitHub's private
vulnerability reporting for this repository: open the repository's **Security**
tab and choose **Report a vulnerability**.

Do not open a public issue, and do not post secrets, tokens or customer data in
a report. Include the release (`botctl version`), what you did, and what you
saw.

## Supported versions

Security fixes go into the latest release.
