# NEXA

نکسا یک ربات تلگرام است که به شما کمک می‌کند سرویس‌های VPN و پروکسی بفروشید و مدیریت کنید.
مشتری‌ها داخل تلگرام سرویس می‌خرند، تمدید می‌کنند و موجودی خود را می‌بینند.
شما همه‌چیز را از یک پنل مدیریت فارسی کنترل می‌کنید.
بعد از پرداخت، سرویس خودکار روی پنل‌های خودتان ساخته می‌شود.

## تصاویر

تصاویر همراه نسخه نهایی اضافه می‌شود.

## چه کارهایی می‌کند؟

- فروش، تمدید و افزایش حجم یا زمان سرویس، داخل ربات تلگرام.
- یک فروشگاه کوچک داخل خود تلگرام (مینی‌اپ).
- پرداخت از چند درگاه و همچنین کارت به کارت با تأیید خودتان.
- کار با پنل‌های Marzban و 3x-ui و RickPanel.
- پنل مدیریت فارسی برای مشتری‌ها، قیمت‌ها، تخفیف‌ها و گزارش‌ها.
- پشتیبان‌گیری رمزگذاری‌شده و امکان بازگردانی.
- بازگشت به نسخه قبلی، اگر بعد از به‌روزرسانی مشکلی پیش آمد.

## قبل از شروع به این‌ها نیاز دارید

1. **یک سرور** (کامپیوتری که همیشه روشن است و اینترنت دارد) با سیستم‌عامل Ubuntu 22.04 یا 24.04.
2. **یک دامنه** (آدرس سایت، مثل `admin.example.com`) که به آدرس سرورتان وصل شده باشد.
   این کار را در بخش DNS سایتی که دامنه را از آن خریده‌اید انجام می‌دهید.
3. **توکن ربات** (یک رمز طولانی که ربات شما را می‌شناسد). از ربات BotFather در تلگرام می‌گیرید.
4. **شناسه عددی تلگرام خودتان** (یک عدد مثل 123456789، نه نام کاربری). از رباتی مثل userinfobot می‌توانید بگیرید.

درگاه‌های 80 و 443 سرور باید باز باشند.

## نصب، قدم به قدم

۱. به سرور وصل شوید. باید یک ترمینال باز کنید (پنجره‌ای که با تایپ دستور کار می‌کند)
و با SSH به سرور وصل شوید. مثلاً `ssh root@آدرس-سرور`.

۲. این دستور را کپی کنید، در ترمینال بچسبانید و Enter بزنید:

```bash
curl -fsSLO https://github.com/Mhoseinshah1/nexa-bot/releases/latest/download/install.sh{,.sha256} && sha256sum -c install.sh.sha256 && sudo bash install.sh
```

۳. نصب‌کننده چند سؤال می‌پرسد. به ترتیب جواب بدهید:

- **دامنه:** آدرس دامنه‌تان را بنویسید، مثل `admin.example.com`.
- **ایمیل:** یک ایمیل واقعی بدهید. فقط برای هشدار پایان گواهی امنیتی سایت استفاده می‌شود.
- **نام کاربری مدیر:** هر نامی که می‌خواهید برای ورود به پنل.
- **شناسه عددی تلگرام:** همان عدد قبلی.
- **رمز عبور مدیر:** رمزی انتخاب کنید و بنویسید. موقع تایپ چیزی دیده نمی‌شود. این طبیعی است.
- **توکن ربات:** توکن BotFather را بچسبانید. این هم دیده نمی‌شود.

۴. صبر کنید. نصب چند دقیقه طول می‌کشد. اگر وسط کار خطایی دیدید، پیام را بخوانید،
مشکل را درست کنید و همان دستور را دوباره اجرا کنید. اجرای دوباره بی‌خطر است.

۵. وقتی نصب تمام شد، در مرورگر `https://admin.example.com` را باز کنید (به‌جای آن، دامنه خودتان).
با نام کاربری و رمزی که انتخاب کردید وارد پنل مدیریت شوید.

۶. ربات خودتان را در تلگرام باز کنید و `/start` بفرستید. اگر جواب داد، نصب موفق بوده است.

## کارهای روزمره

دستور `botctl` ابزار مدیریت سرور است. این‌ها را در ترمینال سرور اجرا می‌کنید.

وضعیت سرویس‌ها:

```bash
sudo botctl status
```

گرفتن پشتیبان (یک نسخه یدکی از اطلاعاتتان):

```bash
sudo botctl backup
```

به‌روزرسانی به نسخه جدید. اول `tmux` را باز کنید. `tmux` کاری می‌کند که اگر اینترنتتان قطع شد،
دستور نیمه‌کاره نماند:

```bash
tmux new -s nexa
sudo botctl update vX.Y.Z
```

به‌جای `vX.Y.Z` شماره نسخه‌ای را بنویسید که می‌خواهید.

بازگشت به نسخه قبلی (rollback). این دستور فقط برنامه را به نسخه قبل برمی‌گرداند و اطلاعات شما را عوض نمی‌کند:

```bash
sudo botctl rollback
```

## اگر مشکلی پیش آمد

1. وضعیت را ببینید: `sudo botctl status`. این دستور می‌گوید کدام بخش کار نمی‌کند.
2. گزارش‌ها را ببینید: `sudo botctl logs`. آخرین پیام‌های خطا معمولاً علت را می‌گویند.
3. بعد از یک به‌روزرسانی مشکل پیدا شد؟ `sudo botctl rollback` را اجرا کنید.
4. ربات جواب نمی‌دهد؟ مطمئن شوید دامنه درست به سرور وصل است، بعد `sudo botctl telegram register` را اجرا کنید.
5. هنوز حل نشد؟ در بخش Issues همین مخزن در GitHub، خروجی `sudo botctl version` و `sudo botctl status` را بدون هیچ رمز و توکنی بفرستید.
